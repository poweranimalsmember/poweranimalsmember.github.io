GarageMath Sync is a privately operated utility for comparing and transferring files between the owner's local GarageMath workspace and the corresponding Google Drive folder.

What the Google connection is for

The tool uses the Google Drive API to list files, read file information, upload new files and download new files. It compares SHA-256 checksums to verify transfers and records conflicts for review.

The local configuration is pinned to the owner's existing GarageMath folder. Google Drive authorization is broader than that folder: the requested Drive permission can access the account's Drive files. Folder pinning is an application safeguard, not a limitation imposed by Google on the permission.

Preserve first

The local workspace is authoritative for existing-file conflicts. Divergent files are preserved for review; the synchronization design does not automatically overwrite or delete them.

A controlled pilot

The current installation is limited to designated test directories. Unattended production synchronization and research-engine integrations are not enabled.

About this website

This site explains the utility and its data practices. It does not provide account registration, initiate Google authorization, distribute the private application or host research files, databases or credentials.

Review the privacy policy and terms of use before authorizing the application. Application support is available through the support contact displayed in Google's GarageMath Sync consent screen.
