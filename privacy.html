DATA PRACTICES

Privacy policy

Effective October 10, 2026. This policy describes the privately operated GarageMath Sync utility and this informational website.

Google Drive information

When the owner authorizes the application, it receives authorization credentials used to communicate with Google Drive. It reads file and folder names, identifiers, sizes, modification information and checksums, and reads file contents when downloading or verifying them. It uploads eligible local files to the configured Drive folder.

The application requests Google Drive access to existing files. That permission can access the account's Drive files; the application's local configuration restricts its intended operations to the existing GarageMath folder. This is not Google's narrower per-file permission.

Purpose and use

Drive information and file contents are used to compare the two locations, transfer eligible new files, verify their integrity and identify conflicts. Local reports may contain file paths, identifiers, hashes, statuses and error information. The tool does not use Drive data for advertising, selling data or training artificial-intelligence models.

Storage and disclosure

File copies are stored in the owner's local workspace and corresponding Google Drive folder. Authorization credentials are kept in a separate, access-restricted local directory, not in the public website or ordinary cloud mirror. Reports and synchronization state remain local unless the owner separately chooses to back them up.

Google processes API requests and stores cloud files as part of providing Google Drive. The application does not intentionally share Drive information with unrelated parties. This informational website contains no private research files, credentials or databases.

Retention and owner control

The application does not automatically delete files. Copies, conflict records and reports remain under the owner's control until the owner removes them. The owner can stop synchronization, remove local authorization credentials, or revoke the connection through Google Account connections. Revocation stops future authorized access; it does not erase file copies already stored locally or in Drive.

Website hosting

These static pages do not contain application login, forms, advertising, analytics scripts or application cookies. GitHub Pages hosts the public site and may collect visitor information, including IP addresses, for its own operation and security. See GitHub's privacy statement. Google also maintains its own privacy policy.

Questions and changes

For application privacy questions, use the support contact displayed in Google's GarageMath Sync consent screen. This page will be updated if the application's data practices change. Never post credentials or private research information on public support channels.
